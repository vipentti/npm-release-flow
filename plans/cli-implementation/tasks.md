- [ ] T4 `tag` command: `src/commands/tag.mjs`, break-glass local recovery (concept doc; separate from the automated path): `--version X.Y.Z` required; dry-run prints the plan; `--execute` creates the annotated signed tag `vX.Y.Z` (subject `Release vX.Y.Z`) on the release commit as create-then-verify-then-push (§6, no partial-mutation window), fully verifies it (annotated object, target = release commit, subject, `git verify-tag --raw` exactly one `VALIDSIG` whose primary fingerprint equals env `NPM_RELEASE_FLOW_GPG_FINGERPRINT` (40-hex required)), pushes with the operator's own git credentials, verifies the remote object equals the local one.
